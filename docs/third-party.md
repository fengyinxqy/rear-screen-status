# 第三方依赖与致谢

- [Shizuku](https://github.com/RikkaApps/Shizuku)：手机端独立运行依赖；经用户授权提供 shell 能力。[Apache-2.0 许可](https://github.com/RikkaApps/Shizuku/blob/master/LICENSE)，不随本项目分发。
- [Shizuku API](https://github.com/RikkaApps/Shizuku-API)：Android 端构建依赖，使用 13.1.5 的 api、provider、aidl、shared。[MIT 及版权声明](licenses/Shizuku-API.txt)；从 [Maven Central](https://repo.maven.apache.org/maven2/dev/rikka/shizuku/)获取，AAR 不纳入仓库。
- [JSON-java 20250107](https://github.com/stleary/JSON-java/tree/20250107)：仅供桌面 JVM 解析测试；[上游声明 Public Domain](https://github.com/stleary/JSON-java/blob/20250107/LICENSE)。
- [Android SDK](https://developer.android.com/tools)：本机构建工具，不随仓库分发，适用 [Android SDK 条款](https://developer.android.com/studio/terms)。
- [mi-back-screen](https://github.com/totallynotkasai/mi-back-screen)：背屏实现参考，不是运行依赖；[MIT 许可](https://github.com/totallynotkasai/mi-back-screen/blob/main/LICENSE)。

项目 MIT 许可不替代第三方各自许可。
